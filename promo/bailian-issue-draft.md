## 我做了什么

```
药盒上印的有效期，前提是「一直没拆封」。拆封之后重新起算、却没有任何地方显示的那个期限，才是真正决定这药还能不能吃的——我把它叫第二个时钟。

《第二时钟》就是替你记住第二个时钟的网页应用：

- 内置 1832 种常见药品的开封后有效期 + 23 条剂型兜底规则，全部离线可用（数据内联在单文件里，断网照常查）
- 用百炼 Qwen-VL 拍药盒识别：一次最多 4 张，识别通用名／商品名／规格／剂型／印刷有效期，识别完自动去内置药库带出开封期限并预填
- 查不到的药可联网查询；仍查不到时明确提示「查不到不等于没有期限，请以说明书为准或咨询药师」
- 到期预警：剩 7 天转黄、剩 3 天转红、过期置顶红色横幅；可按家人分类；支持开封计时与储存条件（含冷藏／冷冻）
- 1744 条安全提示随卡片显示（如「在用的胰岛素笔不要放回冰箱，回温会造成剂量不准」）
- 记录只存本机浏览器，无需注册登录
```

### 为什么选百炼（这段建议放在「使用的工具」之后，作为选型依据）

```
同一套提示词、同三张真实药盒照片，与另一家的免费视觉模型做了横向实测：

| 测试图 | 另一家模型 | 百炼 Qwen-VL-Plus |
|---|---|---|
| 云南白药瓶（书法体中文标签） | 云南白药（曾把「云」误读成「古」） | 云南白药，confidence high |
| Panadol 药片（外文商品名压印） | 帕尼培南-倍他米隆钠（音近幻觉，复现两次） | 对乙酰氨基酚片，confidence high |
| 药房分装周药盒（散装药片、无药名） | 未识别（正确） | 复方制剂，confidence low（正确） |

第二行是关键：Panadol 的通用名就是对乙酰氨基酚，Qwen-VL 换算正确；另一家把「Pana…」按读音凑成了一种毫不相干的注射用抗生素。
在一个用来判断「药还能不能吃」的工具里，这个差别是安全性差别，不是效果差别。
```

## 踩坑记录（可选）

```
1. 视觉模型会「按读音编药名」。用另一家模型时，印着 Panadol 的药片被识别成「帕尼培南-倍他米隆钠」——
   一种毫不相干的注射用抗生素，纯粹是「Pana…」音近。即使在提示词里明确写出这个反例去禁止，仍会复发。
   最后是双保险：提示词区分「允许纠正字形误读、严禁跨语言音近猜测」，再加代码闸——
   模型自标 confidence=low 时不拿这个药名去查药库预填，改为提示用户核对。
   错药名叠一个看起来很笃定的天数，比什么都不填危险得多。

2. 换模型不必动前端。前端那份 HTML 已经过完整验收，provider 切换只是「同一个 OpenAI 兼容协议换地址和模型名」，
   于是把选择放在服务端代理里：改一个环境变量即可在百炼与另一家之间切换，前端一行不动、切错了改回去也是一秒钟。
   代理在转发前把请求体里的 model 改写成 qwen-vl-plus，其余字段原样透传（实测百炼对多带的 thinking 参数是容忍的）。

3. 「查不到」不等于「没有期限」。实测很多药在中文互联网上根本查不到开封后能用多久——
   搜到的全是「保质期 1-2 年」那种未开封效期。模型正确地返回了 null 而没有编，
   但界面原来的文案是「联网查询失败，请手动填写」，很容易被读成「这药没有开封期限」。
   已改成明确指向权威来源：「请以药盒说明书为准，或咨询药师／厂家——查不到不等于没有期限。」
```
