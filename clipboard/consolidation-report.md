## 二 实现摘要（全部写入 index_v5.html）

1. **清残留**：删除死代码 `if (false)` 整段旧 IIFE；识别面板去掉置信度格与旧免责声明。全文"置信度"=0。
2. **多图识别（决策2）**：`photoInput` 加 `multiple`，单次取前4张；全部图片经既有 `compressImage`
   压缩后放入同一次 GLM-4V-Flash 调用（messages 内多个 image_url 块 + 文本提示词）；
   提示词改为要求严格 JSON 数组，每个不同药品一个元素 `{name,expiry,open_days,photo序号}`，
   同一药品多张合并、取日期最清晰一张。返回渲染为"识别结果"列表：每行小缩略图 +
   可编辑的名称/印刷效期/开封天数 + 大按钮「添加」，标题行有「全部添加」；识别不到的字段留空；
   小字"识别仅辅助录入,请以包装和说明书为准"；不显示置信度。失败/15秒超时 →
   "识别失败,请手动填写"（半角逗号），表单不受影响。
3. **演示（决策3）**：去掉自动快进（原第二段 wait+改日期已删）；创建演示记录后提示
   "演示药品已加入,请点击顶部「+7天」或「+30天」观看超期预警"；演示记录带成员/储存预设与
   photo:null；无开封计时样例印刷效期=今天+5天（原有逻辑保留）；重复演示先清旧演示数据；
   「重置」恢复真实日期并清全部(演示)记录（原有逻辑保留）。
4. **成员（决策4）**：表单「使用人」下拉（爸爸/妈妈/爷爷/奶奶/我自己/其他…自定义文本框，可空）；
   卡片右上角绿色角标；列表区顶部筛选条「全部」+已出现成员，成员消失自动回落到「全部」，
   无任何成员时整条隐藏。
5. **储存条件（决策5）**：表单四选一按钮组（常温🌤️/阴凉⛱️/冷藏2-8℃❄️/避光🕶️，再点取消=可空）；
   卡片以图标+文字显示；冷藏卡片附小字"❄️ 离开冷藏环境请尽快使用"；样例预设：
   粉尘螨滴剂=冷藏2-8℃，滴眼液=阴凉，其余常温（样例按钮与演示均预填）。
6. **照片（决策6）**：识别行「添加」时把该药品对应的那张已压缩图（模型返回的 photo 序号，
   非法则按行序兜底）原样存入记录 photo 字段，不二次处理；卡片56px缩略图，点击弹大图
   （关闭按钮+遮罩点击+Esc 可关）；手动录入显示💊占位；删除记录连带图（图内联于记录）；
   localStorage 写入失败提示"本地存储空间不足,请删除部分旧记录"（saveState 统一捕获，
   表单提交路径在重置表单后补显，避免被清空）。
7. **到期显示（决策7）**："已过期X天"/"今天到期"保留；停用原因文案改为
   "因印刷有效期到期"/"因开封后有效期到期"（卡片、顶栏横幅判断同步更新）；
   实际停用日期取更早并注明原因、升序排列均保留。
8. **其他**：normalizeRecord 新增 photo 字段兜底（决策9）；识别按钮旁常驻小字"一次最多可选4张照片"。
9. **样例缩减（2026-07-20）**：样例仅保留五件有开封计时的
   （二甲双胍180/滴眼液28/维C180/丹皮酚软膏60/粉尘螨滴剂7），快捷预填与演示选择卡同步只剩五件；
   "无开封天数→印刷效期取今天+5天"演示分支代码保留（自定义录入仍可走到）。
10. **移动端适配（2026-07-20）**：新增 480px 以下 media query——顶部日期独占一行、
    时钟按钮组可换行（修复「+30天」被裁切）；各处按钮触控高度补足≥44px；
    卡片缩小间距、成员角标卡片内容下移避免与药名重叠；弹窗关闭按钮放大。未改动整体布局结构。

不变量核对：录入/编辑/删除、开封计时、时间模拟、localStorage 键名
`medicine_expiry_single_file_v1` 均未改动结构（仅新增可空字段），旧数据可直接读入。
